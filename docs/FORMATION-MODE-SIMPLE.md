# Formation — mode simplifié MeatMaster

## Activer le mode

1. Menu ☰ → **Réglages** (ou barre du bas)
2. **Mode simplifié** → **Activé**
3. Demander l’aide du responsable si besoin

## Critères de réussite (tests terrain)

| Tâche | Objectif | OK si |
|-------|----------|--------|
| Vente comptoir | Boucher | Terminée en &lt; 2 min, ≤ 1 correction |
| Versement | Boucher | Montant + mode + validation sans erreur |
| Valider versement | Fournisseur | Accepter ou refuser en 1 tap par carte |
| Abattage | Fournisseur | Animal + 1 catégorie + 1 boucherie + valider |

## Affiches recommandées (A4)

Pour chaque flux, coller **4 à 6 captures** numérotées :

1. Écran d’accueil (raccourcis)
2. Étape 1 (choix)
3. Étape chiffres (pavé numérique)
4. Écran **Valider** (bouton vert en bas)

Couleur des boutons : **vert = continuer**, **rouge = refuser** (versements fournisseur).

## Rôles

- **Boucher** : Accueil, Vente, Payer, Stock (réception)
- **Fournisseur** : Accueil, Abattage, Versements, Achat

L’administrateur garde l’interface complète.
